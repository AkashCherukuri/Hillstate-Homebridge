# Homebridge Hillstate IOT Plugin

</span>

---

This is a custom plug-in that connects with the Hillstate API and enables Apple Home and **Siri** to control Lights, Heaters and ACs in Hillstate GwanggyoJungangyeok. I have tested this on a Raspberry PI Zero W2.

## Setup

1. Install Homebridge
